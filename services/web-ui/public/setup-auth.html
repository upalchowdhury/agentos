🔐 AgentOS Authentication Setup

The AgentOS UI requires an authentication token to access the API.

For Development:
Click the button below to set a test token in your browser's localStorage.

Manual Token Creation (Production)

For production use, create a proper DID and credential:

  1. Create a DID: 
    curl -X POST http://localhost:3000/api/v1/dids \
  -H "Content-Type: application/json" \
  -d '{"agentType": "admin", "metadata": {"name": "Your Name"}}'
  2. Issue a credential (use the DID from step 1): 
    curl -X POST http://localhost:3000/api/v1/credentials/issue \
  -H "Content-Type: application/json" \
  -d '{"subjectDID": "YOUR_DID_HERE", "claims": {"role": "admin"}, "expiresIn": "90d"}'
  3. Copy the returned token and paste it in browser console: 
    localStorage.setItem('agentos_token', 'YOUR_TOKEN_HERE');
